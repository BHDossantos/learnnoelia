# Learning experience benchmark and implementation

Research date: 18 November 2026. This is a selected set of 15 relevant products, not a defensible market ranking. Online schools, course marketplaces, language apps and study tools solve different problems. Official product/support documentation establishes described capabilities, not comparative educational effectiveness. No claim that LearnNoelia now outperforms these products is justified.

## Implemented changes

1. Guided reading: one original idea or worked case at a time; original content retained. Sequential inline answer keys are split into individual questions. Unknown formats remain intact rather than guessing pairings. Full lesson and lesson map support review and accessibility.
2. Practice: written reasoning and revealable model explanations; six reviewed biology selected-answer conversions match exact source prompts. Structured `practice_questions` supports authored MCQs in any reading lesson. Existing written activities are not automatically converted with fabricated distractors. Multiple-choice feedback is formative and is not written as an official grade.
3. Visual catalog: original illustrative course covers, mapped by subject/title; shared compressed asset. Illustration provenance is recorded alongside assets. These are not authentic photographs or accurate instructional diagrams.
4. Course study tools: four exam slots and twelve quiz slots per course; available activities derive from valid authored source questions. Answer keys are withheld from the assessment client until server evaluation. Questions may recur, explicitly disclosed. Empty/short banks remain unavailable rather than filled with irrelevant questions.
5. Topic flashcards: selected course source material, answer reveal and revisit queue; clear empty states. Existing saved language review remains separately accessible. Navigation carries explicit course context.
6. Teacher sample paper: four fictional responses, inline corrections, comments, individual rubrics totaling 80/100, original/marked toggle and printing. Separate from actual student grades and actual AI output.
7. Family/teacher report demonstration: clearly fictional John Doe, three courses, graded-points denominator, 60% illustrative threshold, ten daily records, late/absent/excused distinctions, course notes and actionable plan. Switching to teacher view preserves evidence and adds existing marking/gradebook destinations.
8. AI report analysis: explicit user action sends only fixed fictional records to the app's existing provider. Authenticated, rate limited, timeout/error handling, and labeled draft requiring teacher review. Never modifies a grade. Real student AI reporting is not enabled by this demo.

## Content and launch limitations

- A four-exam/twelve-quiz structure is not a claim of sixteen independently authored assessments for all courses. Production read-only inventory found 254 published courses, 4,736 raw MCQ entries, no course with 48 MCQ entries and eight with none. Written source questions can increase usable banks; duplicate/malformed questions are excluded. Each runtime plan shows actual availability.
- High-quality unique distractors, balanced learning-objective coverage, difficulty progression and subject-editor review remain required across the catalog. Current exam partitions are course-question-bank segments, not validated psychometric forms. Source diagnostic questions can span later topics.
- The full parent report is a fictional demo. The current real parent screen still uses limited recent records. A production report requires pagination, teacher-approved publication states, grading-policy configuration, a school calendar/timezone and class-session/day attendance reconciliation. No missing evidence should become a failing mark or inferred absence.
- Generated AI narrative needs teacher verification and source review. Availability of a configured key alone does not prove provider/model availability; a failed request is shown honestly.
- Paid tutoring is not enabled here. Existing LinguaFlow production project metadata has no Stripe/LiveKit environment variable names. Visible Stripe connector accounts belong to other product sandboxes. No merchant account is attached by guesswork.

## Acceptance checks

- Biology Practice stays at the lesson URL, on mobile and desktop; no language-only Speak link.
- Each original worked case is separated; explanations remain hidden until requested. MCQ choices can be selected, checked and retried.
- Assessment results distinguish MCQ correctness from written self-review and link to original lessons.
- Topic flashcards show the chosen course, not a generic Spanish card.
- Family report reconciles 8 attended (including late), 1 absent, 1 excused across 10 school days. Seven days have completions; an attended day can have none.
- Teacher paper rubric totals and overall score agree. Fictional data never enters a production gradebook.
